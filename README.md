## 🏢 MPT Analytics → 🎮 NEURAL QUEST

| Layer | Name | Role |
|-------|------|------|
| **Company** | **MPT Analytics** | AI education & analytics platform |
| **Product** | **NEURAL QUEST** | Gamified AI learning platform |

NEURAL QUEST is the flagship product of MPT Analytics — an interactive RPG where you learn AI concepts through missions, boss fights, and skill trees.

---

## 🚀 Features

### 🧙‍♂️ Hero System
5 unique heroes with distinct abilities:
- **Prompt Mage** — Master of prompt engineering
- **Data Hunter** — Data science specialist
- **Auto Engineer** — Automation expert
- **Neural Assassin** — Neural networks prodigy
- **Creator Idol** — Creative AI applications

### 📚 Missions (6+)
| ID | Mission | Difficulty | XP |
|----|---------|------------|----|
| M-001 | What is AI? | Easy | 100 |
| M-002 | Machine Learning 101 | Easy | 200 |
| M-003 | Neural Network Basics | Medium | 350 |
| M-004 | Social AI Agent | Medium | 500 |
| M-005 | AI Ethics Protocol | Hard | 400 |
| BOSS-01 | Build a Chatbot | ★ Boss | 1000 |

### ⚡ Game Systems
- **XP & Leveling** — Quadratic curve, 20 levels
- **Energy System** — Real-time regeneration (1/min)
- **Skill Tree** — 4 skill branches (Prompt Engineering, ML, Data Science, Neural Networks)
- **AI Evaluator** — Keyword-based scoring engine for open-ended answers
- **Boss Fights** — Interactive chatbot battles
- **Sound System** — Web Audio API for feedback tones
- **Streak Tracking** — Daily engagement rewards

## 🚦 Getting Started

```bash
# Clone
git clone https://github.com/Mhaizza/Nauralquest_Roocode.git
cd Nauralquest_Roocode

# Install
npm install

# Dev
npm run dev        # → http://localhost:3000

# Build
npm run build
```
